# `nlink-lab status`

One lab, all of it: its nodes with their kind, image and addresses
(`mgmt0` included), the container ids, links, impairments as they are
now (what `impair` set at runtime is marked), partitions, tracked
processes, and — as root — the named firewall counters.

```bash
nlink-lab status            # the current lab
nlink-lab status wan        # a lab by name (or -L wan)
nlink-lab --json status wan | jq '.nodes[] | {node, addresses}'
```

`--json` prints a `schema_version: 2` document
([status.schema.json](../json-schemas/status.schema.json)) whose
`host_resources` (the mgmt bridge's name, every declared subnet) lets
tools spot collisions between parallel labs. The topology itself is
`nlink-lab export`'s; `nlink-lab ls` lists the labs.
