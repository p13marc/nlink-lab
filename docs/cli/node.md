# `nlink-lab node`

Change a running lab's nodes in place: the topology the lab runs is
edited, validated, and reconciled with `apply` (only the deltas), so
`export` shows the result and `verify` stays clean.

```bash
sudo nlink-lab node add probe --profile router
sudo nlink-lab link add probe:eth0 core:eth3 10.99.0.1/30 10.99.0.2/30
sudo nlink-lab node rm probe          # its links, impairments, memberships go too
sudo nlink-lab node restart web       # a container node, re-attached after the restart
```

`--dry-run` prints the plan. `node restart` recreates a container (its
network namespace with it) and puts back its links, bridge ports, mgmt
veth, sysctls and `run` commands.
