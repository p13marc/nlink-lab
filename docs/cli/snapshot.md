# `nlink-lab snapshot`

Checkpoints of a running lab, under
`<state>/labs/<lab>/snapshots/<name>/`: the topology, the impairments
set at runtime and the partitions.

```bash
nlink-lab snapshot save before-chaos --description "clean baseline"
sudo nlink-lab impair wan:eth0 --loss 30%
nlink-lab snapshot ls
sudo nlink-lab snapshot restore before-chaos --dry-run
sudo nlink-lab snapshot restore before-chaos
nlink-lab snapshot rm before-chaos
```

`restore` runs an `apply` of the saved topology that drops runtime
impairments, then puts the snapshot's back. It restores what nlink-lab
manages, not hand-made `ip`/`tc` edits inside the namespaces.
